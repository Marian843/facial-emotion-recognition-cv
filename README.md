# Facial Emotion Recognition using Deep Learning

A computer vision project for classifying facial emotions from images using deep learning.  
This repository is being developed as a staged portfolio project focused on computer vision, model training, evaluation, and deployment.

## Project Goal
Build a facial emotion recognition system that classifies a face image into one of the following emotions:

- angry
- disgust
- fear
- happy
- sad
- surprise
- neutral

## Project Roadmap
### Version 1
- Explore FER2013 dataset
- Build a baseline CNN for facial emotion classification
- Evaluate performance using accuracy, F1-score, and confusion matrix
- Run inference on single images

### Version 2
- Improve the classifier with transfer learning
- Perform error analysis and model comparison

### Version 3
- Add face detection and real-time webcam emotion recognition
